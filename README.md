🧩 Connessioni - Gioco Quotidiano

Un puzzle game minimalista in lingua italiana ispirato al celebre format di associazione lessicale. Trova 4 gruppi di 4 parole che condividono un legame comune, con un nuovo enigma ogni giorno a mezzanotte.

🎮 Come si gioca

Obiettivo: Trovare i 4 gruppi composti da 4 parole ciascuno.

Selezione: Tocca 4 parole sulla griglia e premi Invia per verificare l'ipotesi.

Errori: Hai a disposizione un massimo di 4 errori prima che la soluzione venga svelata.

Difficoltà dei gruppi:

🟨 Giallo: Diretto e immediato.

🟩 Verde: Caratteristiche fisiche o azioni condivise.

🟦 Blu: Lessico specialistico, gerghi e cultura generale.

🟪 Viola: Trabocchetti, giochi di parole e doppi sensi.

✨ Caratteristiche principali

🗓️ Schema quotidiano: Un nuovo schema deterministico generato automaticamente ogni giorno alle 00:00.

⏳ Conto alla rovescia: Timer sincronizzato a mezzanotte per il rilascio del prossimo puzzle.

📊 Statistiche e Streak: Tracciamento persistente di partite giocate, percentuale di vittoria, serie corrente e record massimo (salvati in localStorage).

🌓 Tema Chiaro / Scuro: Supporto integrato con salvataggio delle preferenze utente.

📱 Mobile-first: Interfaccia reattiva ottimizzata per smartphone, tablet e desktop.

📋 Condivisione Emoji: Copia rapida della griglia dei tentativi per condividere i risultati senza fare spoiler.

⚡ Zero dipendenze server: Funziona al 100% lato client come file singolo statico.

🚀 Come provarlo in locale

Non serve installare Node.js o librerie:

git clone https://github.com/TUO-USERNAME/NOME-REPO.git


Apri il file index.html con qualsiasi browser web (Chrome, Safari, Firefox, Edge).
